# 使用说明（玩家版）

> 面向"只想打开网页玩一玩"的人。不需要安装任何东西。

## 1. 打开网站

- **线上**：访问站点地址（GitHub Pages 链接，形如 `https://<用户名>.github.io/SLBG/`）。
- **本地**：在项目根目录执行 `python server/serve.py`，然后访问 `http://127.0.0.1:8123/`。
  > 不要直接双击 `index.html`：`file://` 协议下浏览器会禁止读取模型、禁止用摄像头。

首次进入会有一个短暂的"装配引擎"过程（约 1–3 秒，模型 12 MB 只在首次加载时下载）。

## 2. 六个页面

| 页面 | 干什么 |
|---|---|
| 首页 | 今日词条、能力概览、快速入口 |
| 游戏 | 六种玩法 + 端侧训练营 |
| 词工坊 | 自己新建词条、传示例图、导出数据包 |
| 词典 | 查词、看动作要点与示例图 |
| 引擎 | 看模型信息、用示例图跑一次推理（排错用） |
| 我的 | 进度、徽章、复习计划、备份与恢复 |

## 3. 游戏怎么玩

### 需要摄像头的（AI 判定类）
- **手势闯关 quest / 限时连击 rush / 保持挑战 hold**：屏幕出题 → 你对着摄像头比手势 → 保持约 1.2 秒 → 判定通过，得分、加 XP、连击。
- 答对会有飘字 +XP、连击计数，并弹出一条该词的**动作要点**；答错会提示**常见错误**，方便你知道哪里不对。
- **只有被模型认识的词才会被出成题**。当前官方 YOLO 只认识「数字 6」；其余词需要先在训练营/词工坊里训练出来。这不是限制，是防止"模型不认识却硬出题"。

### 不需要摄像头的（知识类）
- **记忆翻牌 memory / 手型拼图 puzzle**：认识词形和图，随时能玩。

### 端侧训练营 trainer
在浏览器里训练一个属于你自己的小模型：选词 → 录 5–8 个样本 → 训练 → 评估 → 立刻可玩。全过程不出设备。

## 4. 判定参数可以调

「我的 → 设置与数据」里可以调：
- **保持判定时长**（0.5–3 秒）：手抖或摄像头慢的人可以调长一点；
- **画面镜像**：自拍视角更自然；
- **显示关键点骨架**：想看模型"看到什么"就打开。

## 5. 进度保存在哪里

**保存在你这台设备的浏览器里（localStorage / IndexedDB），没有任何服务器。**

| 内容 | 保存位置 | 说明 |
|---|---|---|
| XP、等级、连续天数、练习记录、徽章、复习计划 | localStorage | 站点内实时写入 |
| 自建词条 | localStorage | 与进度一起导出 |
| 端侧模型与训练样本 | localStorage | 「我的 → 导出完整备份」会带上 |
| 自建词条的示例图 | IndexedDB | 「词工坊 → 导出数据包」会带上 |

**什么情况会丢**：换浏览器、换设备、清理浏览器数据、用无痕/隐私模式关掉窗口。

**怎么保住**：
1. 「我的 → 导出完整备份」→ 得到一个 `slbg-backup-<时间戳>.json`（含进度 + 自建词条 + 端侧模型）；
2. 存到网盘或发给自己；
3. 换设备后：打开站点 → 「我的 → 导入备份」→ 选择该 JSON → 自动恢复并刷新。

建议每隔几天、或每次训练完新词条后导一次备份。

## 6. 常见问题

- **摄像头打不开**：必须用 `https://` 或 `localhost/127.0.0.1` 访问；检查浏览器/系统摄像头权限；不要在其他程序里占用摄像头。
- **一直识别不出来**：确认玩的是模型认识的词；手离镜头 40–60 cm；避免逆光；在「引擎」页跑一次示例图确认模型正常。
- **模型只认识数字 6？**：是的，这是当前数据集的现实。去「词工坊」建词 +「训练营」录样本，几步就能解锁新词。
- **换手机能玩吗**：桌面浏览器体验最好；手机也可以，但训练 YOLO 模型加载较慢，且页面为竖屏优化有限。

## 7. 隐私承诺

- 没有账号、没有后端、不上传任何图片或视频。
- 采集页的拍摄者字段请用编号（如 `S001`），不要写真名。
- 你导出什么、提交什么，完全由你决定；默认不会有任何东西离开你的设备。
