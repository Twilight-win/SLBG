# 数据贡献指南（贡献者版）

> 目标：让"数字 6 之外"的手语词也能被模型认识。
> 一句话流程：**建词 → 录样本 → 导出 → 提 PR → 等下一轮重训**。

## 方式 A：站点内一条龙（推荐，人人可做）

1. **建词**：词工坊 → 填词语、说明、动作要点（tips 一行一条）→ 创建。
2. **录样本**：游戏 → 端侧训练营 → 选中该词 → 开启摄像头 → 采集。
   - 每词 **≥ 20 个样本**（自己玩得爽 5–8 个就够，但要进 YOLO 请多录）；
   - 多角度、多光照、多背景，手离镜头 40–60 cm；
   - 建议同社团多人都录，否则模型只认你一个人（**同人泄漏**会导致指标虚高 10–20 点）。
3. **导出数据包**：词工坊 → 词条卡上的「导出数据包」→ 得到 ZIP，内含：
   - `words.json`：词条定义（词、说明、tips）
   - `samples.json`：MediaPipe 21 点归一化特征（63 维/条）
   - `images/`：你上传的示例图（如有）
   - `README.txt`：说明
4. **提交**：fork 仓库 → 把内容放进 `datasets/<词条名>/` → 提 Pull Request。
   - 在 PR 描述里写明：词条名、样本数、拍摄者人数、图片是否获得出镜授权。

## 方式 B：直接采集图片（给 YOLO 训练用）

站点内「数据任务」游戏：填拍摄者编号 → 选词条 → 连拍。
每张图会保存画面 JPEG + 标注 JSON（词条、拍摄者、YOLO 框、21 点关键点、时间）。

- 有本地服务在跑时，POST 到 `data/captures/` 自动落盘；
- 纯静态打开时，浏览器逐张下载，自己放进 `data/captures/` 即可。

然后由维护者跑：
```bash
python training/prepare_dataset.py --out datasets/slbg_v1
python training/train_yolo.py --data datasets/slbg_v1/data.yaml --epochs 100
python training/export_onnx.py --weights training/runs/<name>/weights/best.pt --classes datasets/slbg_v1/classes.json --imgsz 320
```
（`export_onnx.py` 会自动把 `best.onnx` 与 `manifest.json` 部署到 `app/models/`。）

## 方式 C：手工整理目录

```
datasets/<词条名>/
├── images/            *.jpg
├── labels/            *.txt   # YOLO 格式：class x_center y_center w h（归一化）
└── meta.json          # 词条元数据（见下）
```

`meta.json` 示例（**不要写真实姓名**）：
```json
{
  "signId": "thanks",
  "word": "谢谢",
  "kind": "dynamic",
  "signers": ["S001", "S002"],
  "source": "web-capture",
  "license": "CC BY-SA 4.0",
  "images": [
    { "file": "images/001.jpg", "signer": "S001", "bbox": [0.42, 0.51, 0.22, 0.30], "step": 1 }
  ]
}
```

## 采集规范（决定模型好不好用）

- **数量**：每个词 ≥ 30 张，≥ 3 位不同拍摄者；
- **多样性**：左右手都要有（若社团允许）、不同距离、不同光照、不同背景；
- **清晰**：整只手完整入镜，不要被裁切；
- **一致**：同一个词的动作要统一（先在教学 tips 里写清标准）；
- **防泄漏**：验证集按**拍摄者**划分，不要按图片随机划分（`prepare_dataset.py` 已实现）。

## 隐私与授权清单（提交前自查）

- [ ] 拍摄者字段是编号，不是真名；
- [ ] 图片里没有无关人员的正脸（或已获授权）；
- [ ] 出镜者已书面同意以 CC BY-SA 4.0 公开；
- [ ] 不包含宿舍门牌、证件、聊天记录等背景信息；
- [ ] `meta.json` 的 `source` 只写 `web-capture` / `upload`，不写设备型号。
